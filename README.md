# my_local_calendar_agent

Ever feel like Google Calendar just isn’t “local” enough? Behold, **my_local_calendar_agent**—because your calendar shouldn’t just sync; it should vibe.

### What’s cool about it:
- **Agentic Charm**: Automatically adds local events to your calendar like it’s got a sixth sense for what’s fun nearby.
- **Phone-Friendly**: Perfectly subscribable on-the-go. Even your phone’s calendar will say, “Wow.”
- **Tech Wizardry**: Powered by Python and OpenAI (yes, this repo knows how to impress in the tech stack department).
- **Daily Updates**: Runs a slick GitHub Action to make sure your events are always fresh, like the daily bakery specials—but for plans.

It’s part calendar, part overachiever. Try it, your weekends will thank you.
